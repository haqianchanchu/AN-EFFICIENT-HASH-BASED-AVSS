# Comparison implementations

`protocols/` contains the GoSSamer, SS24, hbACSS, Haven++ and LongLive reference
implementations from the supplied working snapshot. `adkg_protocols/` contains
additional upstream protocol modules. Imports have been updated to the comparisons
namespace. Shared cryptographic and transport code remains under src/.

These are locally adapted reference implementations, not pristine upstream copies.
Performance experiments and cloud launchers are intentionally excluded.
